# Tour Maré — Maré Residencial Pirangi

Tour virtual 360° do Maré Residencial Pirangi (Natal · RN).
Abra `index.html` em um servidor web (GitHub Pages, Netlify ou o site da Bambu).

- `pano/` panorâmicas 360° (JPEG equiretangular)
- `thumb/` miniaturas do menu
- `img/` e `imgthumb/` imagens da galeria / apresentação
- `fonts/` Marcellus e Figtree (OFL), identidade do book
- `lib/` visualizador Pannellum 2.5.7 (MIT)

Para trocar uma imagem: substitua o arquivo em `pano/` e `thumb/` com o mesmo nome.
Imagens ilustrativas, sujeitas a alterações.
